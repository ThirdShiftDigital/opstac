# Changelog

## 0.1.0 — 2026-09-16

### Command desk
- Callouts from the desktop desk can Send via Text, Signal group, Share, or Log only (no longer log-only by default).
- Creating a desk callout fires the same web-push / local alert path as the field app.
- Stand Down from the desk notifies the team (push/alert), matching the confirm copy.
